# Summarise mapped and unmapped read counts from sorted BAM files

Summarise mapped and unmapped read counts from sorted BAM files

## Usage

``` r
summarise_bam_stats(bam_dir = "merged/bam")
```

## Arguments

- bam_dir:

  Directory containing sorted BAM files (default: "merged/bam")

## Value

A data.frame with sample names, mapped and unmapped counts
