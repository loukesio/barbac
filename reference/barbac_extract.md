# Extract barcodes from BAM files (preferred name for \`barbac_xtr()\`)

\`barbac_extract()\` forwards all arguments to \[barbac_xtr()\] and
returns the same result. Both names are supported.

## Usage

``` r
barbac_extract(...)
```

## Arguments

- ...:

  Arguments passed to \[barbac_xtr()\], such as \`bam_file\`, reference
  coordinates or a flank pattern, and \`output_file\`.

## Value

The value returned by \[barbac_xtr()\].

## See also

\[barbac_xtr()\] for the full argument documentation,
\[barbac_extract_stats()\] for summaries of the extracted barcodes.
