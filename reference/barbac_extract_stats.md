# Summarise extracted barcodes (preferred name for \`barbac_xtr.stats()\`)

\`barbac_extract_stats()\` forwards all arguments to
\[barbac_xtr.stats()\] and returns the same result. Both names are
supported.

## Usage

``` r
barbac_extract_stats(...)
```

## Arguments

- ...:

  Arguments passed to \[barbac_xtr.stats()\], such as \`file\` and
  \`barcode_length\`.

## Value

The value returned by \[barbac_xtr.stats()\].

## See also

\[barbac_xtr.stats()\] for the full argument documentation.
